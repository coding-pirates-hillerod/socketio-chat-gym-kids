# VS Code 💻

Vi anbefaler Visual Studio Code (VS Code) til alle projekter i dette repository.

VS Code er gratis og fungerer på Windows, Mac og Linux.

---

## Installer VS Code

Download VS Code:

👉 https://code.visualstudio.com

Installer programmet og start det.

---

## Åbn et projekt

Vælg:

```text
File → Open Folder
```

Åbn projektmappen.

Eksempel:

```text
socketio-chat-gym-kids
```

Du bør nu kunne se alle filer i venstre side.

---

## Åbn terminalen

Vælg:

```text
Terminal → New Terminal
```

eller brug genvejen:

```text
Ctrl + `
```

Terminalen bruges til at installere pakker og starte projekter.

---

## Installer afhængigheder

I terminalen:

```bash
npm install
```

---

## Start projektet

I terminalen:

```bash
npm start
```

eller:

```bash
node starter_file.js
```

afhængigt af projektet.

---

## Anbefalede extensions

Disse extensions er nyttige:

### JavaScript and TypeScript Language Features

Kommer normalt med VS Code.

Giver hjælp til JavaScript.

---

### Prettier

Gør koden pænere automatisk.

Søg efter:

```text
Prettier
```

i Extensions.

---

### Live Server (valgfri)

Kan være nyttig i nogle webprojekter.

---

## Extensions er ikke vigtige

Du behøver ikke installere en masse extensions.

Et projekt kan godt virke uden dem.

---

## Hvis du ser røde streger

Spørg først:

✅ Virker projektet stadig?

Hvis ja, så er det ofte ikke et alvorligt problem.

Prøv:

1. Gem alle filer
2. Genstart VS Code
3. Start projektet igen

---

## Hvis VS Code virker forvirrende

Bare rolig.

Du behøver kun at kende tre ting:

```text
1. Filer
2. Terminal
3. Kør projektet
```

Resten kan du lære senere.

---

## Golden Rule ⭐

Brug tiden på at bygge ting.

Ikke på at konfigurere VS Code.

Hvis projektet virker:

✅ Så er du klar til at kode.

---

## Klar til næste skridt? 🚀

Start med:

```text
projects/01_echo_chat
```

Kør:

```bash
npm install
npm start
```

Åbn derefter browseren og se magien ske.
