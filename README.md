Ingen kedelige slides.

Ingen endeløs teori.

Bare apps.

---

## Hvad er det her?

Socket.IO Chat Gym for Kids er en samling af små projekter bygget med [Node.js](https://nodejs.org/en) og [Socket.IO](https://socket.io/).

Hvert projekt introducerer nogle få nye idéer, samtidig med at det er sjovt at bruge og ændre.

Målet er ikke at lære en masse teori udenad.

Målet er at:

- Starte apps
- Bruge apps
- Ændre apps
- Forstå apps
- Bygge sine egne apps

---

## Sådan fungerer det

Hvert projekt følger den samme proces:

### 1. Brug

Start projektet og prøv det.

Åbn gerne flere browserfaner og se hvad der sker.

### 2. Hack

Lav små ændringer.

For eksempel:

- Skift farver
- Skift brugernavne
- Tilføj emojis
- Tilføj nye funktioner

### 3. Byg

Tilføj dine egne idéer.

## Kom i gang

Installer Node.js.

Klon dette repository.

Start med:

```text
projects/01_echo_chat
```

Installer afhængigheder:

```bash
npm install
```

Start projektet:

```bash
npm start
```

Åbn derefter browseren.

## For forældre, lærere og frivillige

Børn mister hurtigt motivationen, hvis de bruger mere tid på fejl og opsætning end på at bygge noget.

Derfor fokuserer dette repository på:

- Små projekter
- Synlige resultater
- Færdige eksempler der virker
- Progressiv sværhedsgrad
- Læring gennem leg og nysgerrighed

Projekterne er designet, så børn kan starte med at ændre nogle få værdier og gradvist forstå mere og mere af koden.
