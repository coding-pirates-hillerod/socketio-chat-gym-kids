# Level 04 - Nicknames 🎭

Nu får alle brugere et automatisk kælenavn.

Når en bruger åbner chatten, får vedkommende et tilfældigt navn.

Eksempler:

- NinjaLama
- SuperPingvin
- CyberKat
- MegaPirat

## Start projektet

Installer afhængigheder:

```bash
npm install
```

Start serveren:

```bash
npm start
```

Åbn:

```text
http://localhost:3000
```

Åbn gerne flere browserfaner.

## Du lærer

- Arrays
- Tilfældighed
- Data
- Objekter
- Realtidskommunikation

## Prøv dette

Opdater siden flere gange.

Får du forskellige kælenavne?
