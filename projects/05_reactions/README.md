# Level 05 - Reactions ❤️

Ligesom på sociale medier.

Nu kan brugerne sende reaktioner til hinanden.

Tryk på en emoji og se den dukke op hos alle.

## Start projektet

Installer afhængigheder:

```bash
npm install
```

Start serveren:

```bash
npm start
```

Åbn:

```text
http://localhost:3000
```

Åbn gerne flere browserfaner.

## Du lærer

- Flere events
- Realtidsopdateringer
- Brugerinteraktion
- WebSockets

## Prøv dette

Åbn to browserfaner.

Send en besked.

Tryk derefter på ❤️

Kan du se reaktionen hos begge brugere?
