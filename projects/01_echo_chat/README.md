# 01 - Echo Chat 🦜

Din første Socket.IO-app.

Skriv en besked.

Få den tilbage igen.

Så simpelt er det.

---

## Start projektet

Installer projektets pakker:

```bash
npm install
```

Start serveren:

```bash
npm start
```

Åbn browseren:

```text
http://localhost:3000
```

---

## Sådan virker appen

Skriv noget i tekstfeltet.

Tryk på Send.

Serveren sender beskeden tilbage.
