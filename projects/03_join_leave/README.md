# 03 - Join & Leave 👋

Nu kan chatten se, når brugere kommer og går.

Åbn flere browserfaner.

Luk en fane igen.

Se hvad der sker.

---

## Start projektet

Installer projektets pakker:

```bash
npm install
```

Start serveren:

```bash
npm start
```

Åbn browseren:

```text
http://localhost:3000
```

---

## Sådan virker appen

Når en bruger åbner chatten:

```text
En bruger joinede chatten 👋
```

Når en bruger lukker fanen:

```text
En bruger forlod chatten 👋
```

Der vises også hvor mange brugere der er online.
