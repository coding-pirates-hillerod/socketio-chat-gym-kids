# 06 - Drawing Board 🎨

Nu kan alle tegne på den samme tavle.

Åbn flere browserfaner.

Tegn med musen.

Se tegningen dukke op hos alle.

---

## Start projektet

Installer projektets pakker:

```bash
npm install
```

Start serveren:

```bash
npm start
```

Åbn browseren:

```text
http://localhost:3000
```

---

## Sådan virker appen

Hold venstre museknap nede.

Flyt musen rundt.

Alle brugere ser tegningen med det samme.
