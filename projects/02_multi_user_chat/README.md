# Level 02 - Multi User Chat 💬

Nu kan flere personer chatte sammen.

Åbn to browserfaner og se magien ske.

Når én skriver en besked, kan alle andre se den med det samme.

## Start projektet

Installer afhængigheder:

```bash
npm install
```

Start serveren:

```bash
npm start
```

Åbn derefter:

```text
http://localhost:3000
```

Åbn gerne siden i flere browserfaner.

## Du lærer

- Realtidskommunikation
- Flere brugere
- Events
- Broadcast
- WebSockets

## Prøv dette

Åbn to browserfaner.

Skriv en besked i den ene.

Kan du se den i den anden?
