# 08 - Multiplayer Clicker 🖱️

Alle spillere deler den samme score.

Tryk på knappen.

Tallet stiger for alle.

Åbn flere browserfaner og prøv det sammen.

---

## Start projektet

Installer projektets pakker:

```bash
npm install
```

Start serveren:

```bash
npm start
```

Åbn browseren:

```text
http://localhost:3000
```

---

## Sådan virker appen

Klik på knappen.

Alle brugere ser den samme score.
