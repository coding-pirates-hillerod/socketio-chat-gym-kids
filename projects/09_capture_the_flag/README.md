# 09 - Capture The Flag 🚩

Et lille multiplayer-spil.

Find flaget hurtigere end de andre spillere.

Når nogen finder flaget, flytter det til et nyt sted.

Alle ser ændringerne med det samme.

---

## Start projektet

Installer projektets pakker:

```bash
npm install
```

Start serveren:

```bash
npm start
```

Åbn browseren:

```text
http://localhost:3000
```

Prøv gerne med flere browserfaner.

---

## Sådan virker spillet

Klik på flaget.

Hvis du rammer det:

✅ Du får et point

✅ Flaget flytter sig

✅ Alle ser det nye flag

---

## Du lærer

✅ Positioner

✅ Spillogik

✅ Realtidsspil

✅ Synkronisering
