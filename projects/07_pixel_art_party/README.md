# 07 - Pixel Art Party 🟨🟦🟥

Byg pixelkunst sammen.

Alle ser ændringerne med det samme.

Klik på en pixel for at farvelægge den.

---

## Start projektet

Installer projektets pakker:

```bash
npm install
```

Start serveren:

```bash
npm start
```

Åbn browseren:

```text
http://localhost:3000
```

---

## Sådan virker appen

Klik på en pixel.

Pixlen bliver farvet.

Alle andre ser ændringen med det samme.
