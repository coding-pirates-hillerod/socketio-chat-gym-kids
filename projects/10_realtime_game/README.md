# 10 - Realtime Game 🎮

Nu samles alt det, du har lært.

Flyt din figur rundt.

Saml stjerner.

Se de andre spillere bevæge sig i den samme verden.

---

## Start projektet

Installer projektets pakker:

```bash
npm install
```

Start serveren:

```bash
npm start
```

Åbn browseren:

```text
http://localhost:3000
```

Prøv gerne med flere browserfaner.

---

## Sådan virker spillet

Flyt din figur med piletasterne.

Saml stjerner.

Alle spillere ser den samme verden.
